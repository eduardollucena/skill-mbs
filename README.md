# Skill MBS

Skill para planejar, produzir e refinar vídeos publicitários e demos de produto em motion design com Remotion.

## Instalação no Codex

Copie esta pasta inteira para `~/.agents/skills/skill-mbs/`, mantendo `SKILL.md`, `references/` e `agents/` juntos. Se a skill não aparecer, reinicie o Codex.

Para instalar a partir deste repositório privado, primeiro aceite o convite de colaborador no GitHub e clone ou baixe o repositório com sua conta autenticada.

## Uso

Peça ao Codex para usar `$skill-mbs` em uma tarefa de produção ou revisão de vídeo com Remotion. A skill depende das skills Remotion citadas em `SKILL.md` quando elas estiverem disponíveis no ambiente.
